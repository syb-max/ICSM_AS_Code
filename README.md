# ICSM-AS

- [Original ICSM-AS v2 code framework](ICSM_AS_Code_Framework_20261117_v2.zip)
- [Independent imperfect-CSI evaluation extension](imperfect_csi/README.md)

The extension separates estimated-CSI selection from true-channel capacity scoring without modifying the original network. The original experiment inputs and frozen checkpoints are needed to reproduce published numerical results. The optional synthetic error protocol is explicitly identified as a new evaluation configuration.
